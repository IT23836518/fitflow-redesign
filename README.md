# FitFlow Redesign

## Overview

FitFlow is a fitness application redesign that provides personalized
workout plans, nutrition tracking and social sharing features.

## Technology Stack

- Frontend: Flutter
- Backend: Node.js / NestJS
- AI Service: Python / FastAPI
- Database: PostgreSQL
- Authentication: Firebase Authentication
- Cache: Redis
- Real-time: WebSocket / Socket.IO

## Project Structure

- frontend/ – Flutter application
- backend/ – NestJS backend
- ai-service/ – AI microservice
- docs/ – Project documentation

## Main Features

- User authentication
- Personalized workout plans
- Nutrition tracking
- Social sharing
- AI-based recommendations
- Real-time updates
